# 共用カタログの運用

共用カタログ（作者さんが登録した作品の住所録）は、別のリポジトリ [seihayukimi-oss/cardwirth-catalog](https://github.com/seihayukimi-oss/cardwirth-catalog) で運用しています。くわしい文書は、そちらにあります。

| 文書 | 中身 |
|---|---|
| [登録のしかた.md](https://github.com/seihayukimi-oss/cardwirth-catalog/blob/main/docs/登録のしかた.md) | 作者さん・代理で登録する方向けの手順 |
| [管理のしかた.md](https://github.com/seihayukimi-oss/cardwirth-catalog/blob/main/docs/管理のしかた.md) | 管理人・副管理人向け（管理ページ・作品の状態・Discord の知らせ） |
| [通報の決まり.md](https://github.com/seihayukimi-oss/cardwirth-catalog/blob/main/docs/通報の決まり.md) | 通報の理由と、一時保留になる人数・IP の扱い |
| [データの形.md](https://github.com/seihayukimi-oss/cardwirth-catalog/blob/main/docs/データの形.md) | 作品のデータ（このリポジトリの [データ形式.md](データ形式.md) に、管理用の項目を足したもの） |

## CWカタログとのつながり

- CWカタログは、共用カタログの `meta.json` → `index.json`（R18 をONにした人だけ `index-r18.json`）を読みます。書き換えはしません
- カタログの `links` に、登録・変更と解除・通報のページの URL が入っています。CWカタログは、作品の画面の「登録内容の変更・解除」「通報する」を `?id=作品ID` つきで開きます
- 注意のラベルの種類は、カタログの `content_labels` で増えます（アプリを更新しなくても使えます）
- 安全の報告は、このリポジトリの Private vulnerability reporting でまとめて受けます（[SECURITY.md](../../SECURITY.md)）。届くと、共用カタログの受付が運営者の Discord に知らせます
