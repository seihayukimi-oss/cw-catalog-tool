## 次の版（運営者の確認待ち）
### 要点
- カタログのタグ（作者様推奨タグ）を、自分のタグとして付けたり、自分のフォルダ一覧で見たりできるようにしました。
### もっと詳しく
- 【タグ】シナリオを入れるとき、カタログのタグ（作者様推奨タグ）も自分のタグとして付けられるようにしました。（最初はオフ。「次回から自動で付ける」にチェックすると、次からも付けます。「設定」の「タグ」で戻せます）
- 【タグ】自分のフォルダ一覧に、カタログのタグ（作者様推奨タグ）を表示するようにしました。押すと自分のタグに足せます。（作品ごとに「隠す」、または「設定」の「タグ」でまとめて隠せます）
- 【タグ】自分のフォルダ一覧の選択モードに、「カタログのタグを付ける」「推奨タグを隠す」「推奨タグを表示」を追加しました。
- 【タグ】Readmeから付ける対象レベルのタグを、「Lv3以上」「Lv5以下」のように下限と上限に分けて付けるようにしました。（これまでは「Lv3-5」）
- 【タグ】個人用カタログに登録するとき、タグも引き継ぐかを「設定」の「タグ」で選べるようにしました。（最初はオン）
- 【設定】「タグ」のチェックを、1つずつ行を分けて見やすくしました。
- 【カタログ】作者様ご本人が登録した作品に、サイト認証をしたサイトを「作者本人（認証：○○）」と表示するようにしました。（同じ名前の別の作者様を見分けられます）
- 【カタログ】「この作者を除外」を、サイト認証のある作品では「名前＋認証したサイト」で覚えるようにしました。同じ名前でも、別のサイトで認証した作者様の作品は表示したままにします。（前に除外した作者様は、今までどおり名前で除外します）
- 【設定】「クレジット」に、はじめに・コード署名ポリシー・使っている部品の一覧・部品の許諾文の、最新を開けるボタンを追加しました。（自動更新では、同じフォルダの はじめに.txt などのテキストは変わらないため）
- 【配布物】コード署名ポリシー（CODE_SIGNING_POLICY.txt）を、今の状態（コード署名はまだしていないこと）に合わせて直しました。（新しくダウンロードした zip に入っています）
- 【配布物】部品の許諾文（THIRD-PARTY-NOTICES.txt）を、リリースのファイルとしても置くようにしました。
