# CWカタログ（ツール）

CardWirth（1.50／Next 1.60／Py）のシナリオを、**一括ダウンロードする・正しいフォルダに入れる・自分のフォルダにあるものを一覧にする・更新を確かめる**ためのツールです。

- **アプリ版（ポータブル版・Windows）**：インストール不要。好きなフォルダに置いた `CWCatalog.exe` を起動するだけ。設定や記録は横の `CWCatalog-data` に入るので、やめるときはフォルダごと消せばおしまい。作者さんのサイトからの直接ダウンロード（同意ページ・DLキー・Google ドライブなども）、配布ページの更新チェック、CardWirthの起動ができる。「更新を確認」で、署名を確かめてから新しい版に入れ替えられる
- **HTML版**：`cw-catalog.html` をChrome・Edgeで開くだけ。インストール不要。WebCardWirth用のzipの書き出しもできる

使い方は、配布物に入っている [はじめに.txt](package/はじめに.txt) にも書いてあります。

どちらも中身（画面と処理）は同じです。

## シナリオラベル（R18・R15・注意のラベル）

- 作品に、対象年齢（`rating`：全年齢・R15・R18）と、注意のラベル（`content`：グロ・残酷描写／ホラー／性的な表現（R15相当）。共用カタログの `content_labels` で管理人が増やせる）を付けられます
- R18 は初期状態では非表示です。設定でONにするとき、このパソコンで一度だけ年齢を確認します（パソコンが変わったり、アプリを入れ直したりしたら、もう一度）
- R18 の作品は、アプリの中ではダウンロードせず、配布元をお使いのブラウザで開きます。紹介の画像と説明は、押したときだけ出します
- 「特定のラベルを持つ作品を非表示にする」を、ラベルの種類ごとに選べます
- 共用カタログは、R18 の作品を `index-r18.json` に分けて、ONにした人だけが取りに行きます

## 安全のために

- 書き込むのは、登録したエンジンの `Scenario` と `CWCatalog_backup` フォルダ、それと指定したzip・wsnの保存場所だけです。宿（Yado）には触りません
- zipの中のファイルを実行することはありません
- URLやページは、アプリ（Rust）が直接読みます。ページのスクリプトは動かさず、文章とダウンロードのリンク・同意のボタンだけを取り出して文字として見せます。サイトのCookieはアプリを開いている間だけメモリに置き、保存しません
- ダウンロードしたものはパソコンに書き込まず、メモリの中だけで確かめます（アプリ版）。書き込むのは、インストールすると決めたものだけです（アプリ内ブラウザでボタンを押したときだけは、一度ファイルになり、読んだらすぐ消します）
- このアプリはウイルス対策ソフトではありません。入れたファイルは、Windowsのウイルス対策が見張ります。http（暗号化なし）のURLには注意を出します
- 同じ説明を、アプリの「設定」→「安全のしくみ」と、取ってくる画面の「くわしく」に出しています
- シナリオ以外の実行ファイル（.exe .bat .cmd .vbs .ps1 .scr .lnk など。拡張子が変更されている場合も、ファイル先頭の `MZ` 等のヘッダー識別印で判別します）が入っていたら、「⚠ 注意！このファイルには、カードワースのシナリオ以外の実行ファイルが入っています」と出し、いつもは外して入れます（本人が選べば入れられます）。外したときは、元のzipも保存場所に残しません
- 入れる前に「中身の一覧」を見られ、テキストはその場で読めます
- アプリ版では、カタログの作品を、ダウンロードせずに「中身を見る」（ファイルの一部だけを読んで目次を見る。zip・wsn・cab・7z）と「リンクを確かめる」（リンク切れなら「✖ リンク切れ」の印）ができます。更新チェックのときも、入れている作品のDL先を1週間に1回確かめます
- zipの `../` などの危険なパス、異常なサイズ・圧縮率、壊れたファイル（CRC不一致）は止めます
- Readmeやカタログの文字は、HTMLとして解釈せず文字として表示します
- ネットにつなぐのは、ボタンを押したときだけです
- 同意ページは、ページの文章を見せて、本人が「同意します」にチェックしてからでないと送信しません
- アプリ内ブラウザの窓は外部のページなので、アプリの機能（ファイル操作など）には一切触れられない設定です
- HTML版は、ファイルに埋め込んだスクリプト以外を実行しない設定（CSP）になっています
- アプリ版は、ユーザーがダイアログで選んだフォルダにしか触れません（Tauriの権限設定）。選んだフォルダは `CWCatalog-data` に覚えます
- アプリの更新は、GitHubのリリースからだけ取り、アプリに埋め込んだ公開鍵で署名を確かめてから入れ替えます
- Windowsへの登録（.wsn・右クリック・cwcatalog://）は、設定で押したときだけ、自分のユーザー用の場所（HKEY_CURRENT_USER）に書きます
- 部品は最小限にし、版を固定しています（出てから2週間以上たった版のみ。インストール時のスクリプトは無効）

## 起動時に警告・ブロックの画面が表示された場合（Windows）

- 「WindowsによってPCが保護されました」（青い画面）：「詳細情報」→「実行」で起動できます
- 「このアプリは保護のためにブロックされました」（赤い画面）：CWCatalog.exe を右クリック →「プロパティ」→「全般」タブの一番下の「ブロックの解除」にチェック →「OK」のあと、もう一度起動してください

## スマート アプリ コントロールにより起動がブロックされた場合（Windows 11）

コード署名をしていない現在のアプリ版は、Windows 11 の「スマート アプリ コントロール」がオンだと起動がブロックされることがあります（「詳細情報」→「実行」や「ブロックの解除」では開けません）。

- **いちばん安全なのは HTML版**（`cw-catalog.html` を Chrome・Edge で開くだけ）です。exe ではないためブロックされません
- オフにする場合：「Windows セキュリティ」→「アプリとブラウザーコントロール」→「スマート アプリ コントロールの設定」→「オフ」
  - **注意：画面に「再インストールしないとオンにできません」と出たときは、一度オフにすると Windows を入れ直すまでオンに戻せません。** よく考えてから決めてください
  - オフにしても、ウイルス対策（Microsoft Defender）はそのまま働きます
- コード署名をした版を準備中です
