CWカタログ（ポータブル版）
==========================

CardWirth（1.50・Next・Py）のシナリオを、まとめてダウンロードし、適切なフォルダへ配置・
更新確認を行うためのツールです。インストール不要でそのままご利用いただけます。

本アプリは、group Ask制作の RPG「Card Wirth」の追加プラグインツールです。
プレイには CardWirth 本体が必要です。ご利用前に各自データのバックアップを行ってください
（詳細は最下部の「クレジット・ライセンス」をご確認ください）。


■ 起動方法
  CWCatalog.exe をダブルクリックして起動してください。

  ・CWCatalog.exe は、書き込み権限のある通常のフォルダに配置してください。
    （例：D:\ゲーム\CWCatalog）
    ※「C:\Program Files」内に配置すると、設定の保存や更新が正しく行えません。
  ・起動時に Windows の警告画面が表示された場合は、下記の
    「■ 起動時に警告・ブロックの画面が表示された場合」をご確認ください。


■ 起動時に警告・ブロックの画面が表示された場合
  現在の CWCatalog.exe はコード署名を行っていないため、Windows のセキュリティ機能により
  警告やブロックの画面が表示されることがあります。表示された画面に合わせて対処してください。

  ●「WindowsによってPCが保護されました」と表示された場合（青い画面）
    コード署名をしていないアプリを初めて起動した際に、Windows SmartScreen が表示されます。

    1. 画面内の「詳細情報」というテキストをクリックします
    2. 右下に表示される「実行」ボタンを押すと起動できます

  ●「このアプリは保護のためにブロックされました」と表示された場合（赤い画面）
    ※この画面では「詳細情報」を押しても「実行」ボタンが表示されない場合があります。
    その場合は、以下の方法でブロックを解除してください。

    1. CWCatalog.exe を右クリックして「プロパティ」を開く
    2.「全般」タブの一番下にある「ブロックの解除」にチェックを入れて「OK」
       （「ブロックの解除」の項目が表示されない場合は、すでに解除されています）
    3. 再度 CWCatalog.exe をダブルクリックして起動する

  ●「スマート アプリ コントロール」により起動がブロックされた場合（Windows 11）
    下記の「■ スマート アプリ コントロールにより起動がブロックされた場合」をご確認ください。


■ スマート アプリ コントロールにより起動がブロックされた場合（Windows 11）
  Windows 11 の「スマート アプリ コントロール」がオンになっている場合、
  コード署名のないアプリ（現在の CWCatalog.exe）は起動がブロックされることがあります。
  この状態では「詳細情報」→「実行」や「ブロックの解除」から開くことはできません。

  ★ 最も安全・簡単な解決策：HTML版を使用する
    同じフォルダにある cw-catalog.html を、Google Chrome や Microsoft Edge で開いてください。
    exe ファイルではないため、スマート アプリ コントロールの影響を受けずにご利用いただけます。
    （※作者様サイトからの直接ダウンロード機能など、一部機能はアプリ版限定となります）

  ★ スマート アプリ コントロールをオフにする場合
    【重要なご注意】
    設定画面に「再インストールしないとオンにできません」と表示される場合、
    一度オフにすると Windows を再インストール（初期化）するまで再度オンに戻せなくなります。
    設定変更は慎重に行ってください。迷った場合は上記の「HTML版」のご利用をおすすめします。

    1. スタートメニューから「Windows セキュリティ」を開く
    2. 「アプリとブラウザーコントロール」を選択
    3. 「スマート アプリ コントロールの設定」を選択
    4. 「オフ」を選択（※上記の注意事項をよくご確認ください）
    ※オフにした場合でも、通常のウイルス対策（Microsoft Defender）は正常に機能します。

  ★ 今後の対応予定
    コード署名を実施したバージョン（ブロックされずに起動できる版）の準備を進めております。
    準備が整い次第、設定を変更せずにお使いいただける予定です。


■ シナリオラベル（R18・R15・注意ラベル）について
  作品には、対象年齢（R18・R15）および注意ラベル（グロ・残酷描写／ホラー／性的な表現（R15相当））が
  設定されている場合があります。これらを総称して「シナリオラベル」と呼びます。

  ・R18（成人向け）作品は、初期状態では非表示になっています。
    「設定」→「シナリオラベル」にて「R18（成人向け）作品を表示する」をONにすることで表示されます。
    ※ONに切り替える際、初回のみ18歳以上であるかの確認ダイアログが表示されます。
      （別のPCで起動した場合や、アプリを入れ直した場合は、再度確認が行われます）
  ・R18作品はアプリ内での直接ダウンロードを行わず、お使いのブラウザで配布元ページを開きます。
    入手したファイルは「『ダウンロード』から選ぶ」機能で追加してください（一括ダウンロードの対象には含まれません）。
  ・R18作品の紹介情報（画像・説明文）は、該当項目を選択した際のみ表示されます（設定で常時表示も可能）。
  ・R15および注意ラベル付きの作品は、該当ラベルが付与された状態で表示されます。
    「特定のラベルを持つ作品を非表示にする」設定により、ラベルの種類ごとに非表示にできます。
  ・ローカル（自分のフォルダ）に保存済みの作品は、R18設定がOFFの場合でもそのまま表示されます。
  ・ダウンロード一覧を他者に共有・送付する際、R18作品は「R18の作品も含める」にチェックを入れた場合のみ出力されます。


■ 同梱内容
  CWCatalog.exe     … アプリ本体（ポータブル版）
  cw-catalog.html   … HTML版（Chrome / Edge 等のブラウザで開くだけで使用可能）
  はじめに.txt       … 本ファイル
  THIRD-PARTY-NOTICES.txt … 本アプリが使用している部品（ライブラリ）の許諾文

  起動すると、CWCatalog.exe と同じ場所に以下のデータが生成されます。
    CWCatalog-data … 設定データ・履歴・アプリ内ブラウザのログイン状態
    CWCatalog_保存 … 標準の保存用フォルダ
        zip保存 … 取り込んだシナリオの元zip・wsnファイル（素材・スキンは各専用フォルダ内）
        素材    … 画像・音声等の素材置き場
        スキン  … CardWirthPy 用スキンの置き場
  ※保存フォルダの位置は「設定」画面から変更可能です。
  ※取得画面の「保存先を選ぶ…」から、素材・スキン・元zipの保存場所を個別に指定することも可能です
    （「今回のみ」または「次回以降も適用」を選択可能）。

  ダウンロードやインストールの進捗状況は、画面右上に表示されます。
  （サーバーに接続中 → ダウンロード中 → データを検証中 → 保存中 → インストール中）


■ アップデート方法
  アプリ内の「設定」→「アプリの更新」→「更新を確認」を選択してください。
  最新バージョンが存在する場合、署名（データの正当性）を検証した上で自動で差し替えを行い、再起動します。
  ※起動時に自動で更新確認を行うかどうかも同画面で設定可能です。
  ※各バージョンの変更内容は「設定」の最下部「更新履歴」で確認できます。

  自動更新が行えない場合は、GitHubのリリースページから最新の CWCatalog.exe を取得し、
  既存の CWCatalog.exe と上書き差し替えを行ってください（CWCatalog-data フォルダはそのまま引き継がれます）。
  https://github.com/seihayukimi-oss/cw-catalog-tool/releases


■ アプリの削除方法（アンインストール）
  1. 「設定」→「Windows設定との連携」を登録している場合は「登録を外す」を選択
  2. CWCatalog.exe および CWCatalog-data フォルダをまとめて削除
     （※CWCatalog_保存 フォルダには保存したzipや素材が入っています。不要な場合のみ一緒に削除してください）
  上記の手順で削除は完了です。


■ 他者へ配布・共有する場合
  【アプリ版（ポータブル版）】
  ・CWCatalog.exe 単体のみを配布してください。
    ※CWCatalog-data フォルダには、アプリ内ブラウザのログインセッション情報等が含まれるため、
      他者へ渡さないようご注意ください。

  【HTML版】
  ・cw-catalog.html のファイル1つをそのまま渡せます。
    設定や記録はファイルの中ではなく、開いたブラウザの中に保存されるため、
    ファイルを渡しても、ご自身の設定・記録・ログイン情報が相手に渡ることはありません。
  ・ファイルを渡す代わりに、公開ページのURLを案内することもできます（常に最新版が開きます）。
    https://seihayukimi-oss.github.io/cw-catalog-tool/cw-catalog.html


■ セキュリティ・動作仕様について（ダウンロード・インストール時）
  ※同様の説明は、アプリ内「設定」→「安全のしくみ」および取得画面の「詳細」からも確認できます。

  【URL・ページの読み込み】
  ・アプリが直接対象サイトと通信を行います。通常のブラウザのようにページ内のスクリプト（JavaScript 等）を
    実行することはありません。
  ・取得したページはそのまま表示せず、本文・ダウンロードリンク・同意ボタン等の必要な情報のみを抽出し、
    テキストとして表示します（ページのレイアウトや広告等は表示されません）。
  ・同意ページやDLキー入力ページでは、ご本人が「同意する」へのチェックやキーの入力を行った場合のみ送信します。
  ・サイトから受け取ったCookie（同意の識別用など）は、アプリの起動中のみメモリ上に保持し、PCには保存しません。
    同じサイトとの通信時のみ送り返します。
  ・転送（リダイレクト）は最大10回まで、ファイル容量は2GBまでに制限しています。
    http / https 以外のURLは読み込みません。

  【ダウンロード】
  ・ダウンロードしたデータは、PCのドライブへ直接書き込まず、まずメモリ（RAM）上でのみ受信します。
  ・内容を検証し、インストールが確定したデータのみを指定の保存先へ書き込みます。
  ・アプリ内ブラウザでダウンロードボタンを押した場合のみ、仕組み上 CWCatalog-data 内に一時ファイルが
    作成されますが、読み込み後ただちに削除します（開いたり実行したりすることはありません）。
  ・アプリ内ブラウザでのダウンロード中は、受信量を確認して画面右上に進捗を表示します
    （ファイルの大きさを確認するだけです）。

  【ファイルの検証】
  ・zip などの内部ファイルは、ファイル名とデータ先頭部分（ヘッダー）の読み取りのみを行います。
    ファイルを開いたり実行したりすることは一切ありません。
  ・シナリオに含まれない実行ファイル（.exe .bat .cmd .vbs .ps1 .scr .lnk など）を検出した場合は
    警告を表示し、初期状態では除外してインストールします。
    拡張子が変更されている場合も、ファイル先頭の「MZ」等のヘッダー識別印で判別します。
    ※除外した場合は、元のzipファイルも保存先へ残しません。
  ・インストール前に「中身の一覧」を確認できます。テキストファイルはその場で内容を閲覧できます。
  ・「../」などを含む危険なパス、異常なサイズや圧縮率のファイル（zip爆弾）、
    破損したファイル（CRC不一致）は処理を中止します。
  ・カタログの作品は「中身を見る」で、ファイル本体をダウンロードせずに
    目次情報（ファイル構成とサイズ）のみを確認できます。
    読み込むのはファイルの一部（目次部分）だけで、保存もしません
    （ごく小さいファイルは全体を読み込む場合があります）。

  【リンク確認】
  ・ファイルの先頭データ（ほんの1バイト）のみをリクエストし、サーバーの応答コード（404エラー等）を確認します。
    ファイル本体のダウンロードは行いません。
    サーバーの負荷を抑えるため、同じサイトへの確認は1件ずつ間隔を空けて行います。

  【アプリ内ブラウザ】
  ・ログインが必要なサイトや、ボタン操作をしないとダウンロードできないサイトでのみ使用します。
    ページ内のスクリプトは、通常のブラウザと同様に動作します。
  ・アプリ内ブラウザのウィンドウには、アプリ本体の機能（ファイル操作など）へアクセスする権限を一切与えていません。
  ・ログイン状態（セッション）は CWCatalog-data 内に保持されます。

  【書き込み対象の制限】
  ・本アプリが書き込みを行う対象は、登録されたエンジンの「Scenario」「CWCatalog_backup」フォルダ、
    指定された zip・wsn の保存先、素材・スキンの置き場所、バックアップ先、および CWCatalog-data のみです。
    ※宿（Yado）のデータへ変更を加えることはありません。
  ・外部ネットワークへの接続は、ユーザー操作時および起動時の更新確認時（設定でオフ可能）のみ行われます。

  【免責・制限事項（重要）】
  ・本アプリはウイルス対策ソフトではありません。取り込んだファイルの監視は、Windows の標準セキュリティ
    （Microsoft Defender 等）に依存します。
  ・暗号化されていない通信（http）のサイトからダウンロードする場合、通信途中でデータが改ざんされる
    リスクが少なからず存在します。インストール前に「中身の一覧」および実行ファイルの警告の有無を
    必ずご確認ください。
