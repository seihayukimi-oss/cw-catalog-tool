# 共用カタログの登録フォーム（管理人向け）

CWカタログの「共用カタログ」を、**Googleフォーム＋スプレッドシート＋Google Apps Script** で動かすための一式です。
作者さんも、代理で登録する方も、GitHubのアカウントは要りません（Googleアカウントでログインして送ります）。

| ファイル | 中身 |
|---|---|
| `Code.gs` | スクリプト本体（フォームの作成・受け付け・メール・カタログのJSON） |
| `appsscript.json` | 設定（タイムゾーン・ウェブアプリ・使う権限） |

## できること

- **登録フォーム**：種類・作品名・作者名・配布URLだけで登録できます（ほかは任意）
  - 作者さん以外の方の「代理登録」も受け付けます（カタログに「代理登録」の印が付きます）
  - 送信すると、ログインしたGoogleアカウントのメールに **作品ID・編集キー・「回答を編集」のリンク** が届きます
  - 同じGoogleアカウントなら、メールのリンクからいつでも直せます
- **変更・削除フォーム**
  - **内容を直す**：作品ID＋編集キーで、直したい項目だけ書きます（登録したアカウントならキーなしでも可）
  - **掲載をやめる**：作品IDを送ると、**すぐに非公開**になります（管理人にメールが届きます）
  - **サイト認証**：1回目の送信で確認用の文字がメールで届き、それを配布ページか紹介ページに書いてもう一度送ると、本人と確認できます。代理登録の引き取りや、編集キーをなくしたときに使います
  - **編集キーの再発行**：登録したアカウントのメールに送ります
- **台帳**（スプレッドシートの「作品」シート）：「状態」の列で **公開／承認待ち／非公開／削除依頼** を切り替えます。「記録」シートに、だれが何をしたかが残ります
- **カタログのJSON**：ウェブアプリとして公開すると、CWカタログが読む `?file=index`（作品の一覧）と `?file=meta`（変化の確認用）を出します。メールアドレスなどは出しません

## はじめに（1回だけ）

1. https://script.google.com を開いて「新しいプロジェクト」を作り、名前を「CWカタログ 共用カタログ」などにする
2. 左の「プロジェクトの設定」（歯車）で「appsscript.json マニフェスト ファイルをエディタで表示する」にチェック
3. エディタに戻り、`コード.gs` の中身を `Code.gs` の中身で置き換え、`appsscript.json` の中身も置き換えて保存
4. 上の関数の選択で `setup` を選んで「実行」
   - 権限の確認が出たら、自分のアカウントを選んで許可します（「Googleで確認されていません」と出たら「詳細」→「（プロジェクト名）に移動」。自分で作ったスクリプトなので大丈夫です）
   - 実行ログに **台帳・登録フォーム・変更／削除フォーム** のURLが出ます。マイドライブにも作られています
5. 右上の「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」を押して出てくる URL（…/exec）の後ろに `?file=index` を付けたものが、**共用カタログのURL** です
6. CWカタログの「カタログ」→「＋ カタログを追加」→「共用カタログをURLで追加」に、そのURLを入れます
   - カタログの管理に「作品を登録する」「登録を直す・削除を依頼」のボタンが出ます

## ふだんの管理

- 最初は、登録はすべて **承認待ち** になります。台帳を見て、よければ「状態」を **公開** にしてください
  - 承認なしですぐ載せたいときは、「プロジェクトの設定」→「スクリプト プロパティ」の `AUTO_PUBLISH` を `true` にします
- 新しい登録・削除依頼・サイト認証があると、管理人（setup を実行したアカウント）にメールが届きます
  - 届け先を変えるときは、スクリプト プロパティの `ADMIN_EMAIL` を書き換えます
- 削除依頼が来た作品は、すぐに「削除依頼」（非公開）になります。いたずらだったときは「公開」に戻してください
- 同じ作品名・作者名の登録が来たら、台帳の「メモ」に書かれます

## 気をつけること

- Googleフォームの設定で「メールアドレスを収集」が **確認済み** になっているか確かめてください（古い環境では自動で設定できないことがあります）
- 無料のGoogleアカウントでは、メールは1日100通までです
- スクリプトを直したときは「デプロイを管理」→ 鉛筆 →「バージョン：新バージョン」→「デプロイ」。URLは変わりません
- 台帳のメールアドレスは公開しないでください（スプレッドシートの共有設定は「制限付き」のまま）
- 編集キーそのものは保存しません（元に戻せない形で保存しています）。なくしたら再発行かサイト認証です
